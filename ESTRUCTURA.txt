╔═══════════════════════════════════════════════════════════════════╗
║                          FLUJO DEL SISTEMA                        ║
╚═══════════════════════════════════════════════════════════════════╝

1️⃣  REGISTRO
    Usuario → index.html → auth.js → api.php → data/users.json
    api.php → Envía email de verificación
    Usuario → Click en email → verify.php → Usuario verificado

2️⃣  LOGIN
    Usuario → index.html → auth.js → api.php → Valida credenciales
    api.php → Crea sesión → Redirige a dashboard.html

3️⃣  PROPONER LEY
    Usuario → dashboard.html → Nueva Propuesta → app.js → api.php
    api.php → Guarda en data/laws.json

4️⃣  VOTAR LEY
    Usuario → Click en ley → Modal → Vota → app.js → api.php
    api.php → Guarda voto en data/votes/law_[id].json
    api.php → Actualiza contadores en laws.json
    api.php → Evalúa si aprueba/rechaza (10+ votos)

5️⃣  COMENTAR
    Usuario → Escribe comentario → app.js → api.php
    api.php → Guarda en data/comments/[law_id].json

6️⃣  VOTAR COMENTARIO
    Usuario → Upvote/Downvote → app.js → api.php
    api.php → Guarda en data/votes/comment_[id].json
    api.php → Actualiza contadores
    Frontend → Reordena por score (más votados arriba)
