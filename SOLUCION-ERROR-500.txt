- api.php devuelve error 500 (Internal Server Error)
- El navegador muestra "<!doctype..." en lugar de JSON
- Mensajes: "Error de conexión. Intente nuevamente."

═══════════════════════════════════════════════════════════════════
PASOS PARA SOLUCIONAR
═══════════════════════════════════════════════════════════════════

PASO 1: VERIFICAR PHP
----------------------
Accede a: https://neonvintage.com.ar/democracia/check-php.php

Si ves "PHP is working!" → PHP funciona, continúa al Paso 2
Si ves error → Tu servidor tiene problemas con PHP

PASO 2: DEPURAR API
--------------------
Accede a: https://neonvintage.com.ar/democracia/debug-api.php

Verás todos los tests del sistema:
- Si todos muestran ✓ → El problema es específico de api.php
- Si alguno muestra ✗ → Ese componente está fallando

PASO 3: VER ERROR ESPECÍFICO
-----------------------------
Accede a: https://neonvintage.com.ar/democracia/api-simple.php

Este archivo mostrará el error exacto de PHP.

PASO 4: REVISAR PERMISOS
-------------------------
Asegúrate de que los archivos tengan los permisos correctos:
- Archivos .php: 644 o 755
- Directorio data/: 755 (se crea automáticamente)

═══════════════════════════════════════════════════════════════════
SOLUCIONES COMUNES
═══════════════════════════════════════════════════════════════════

PROBLEMA 1: PHP no instalado o deshabilitado
SOLUCIÓN: Contacta a tu hosting para habilitar PHP 7.4+

PROBLEMA 2: Error con .htaccess
SOLUCIÓN: Renombra .htaccess a .htaccess.backup temporalmente

PROBLEMA 3: Permisos insuficientes
SOLUCIÓN: Cambia permisos del directorio a 755

PROBLEMA 4: random_bytes() no disponible
SOLUCIÓN: Ya corregido en la nueva versión de api.php

PROBLEMA 5: session_start() falla
SOLUCIÓN: El servidor necesita permisos para crear sesiones
