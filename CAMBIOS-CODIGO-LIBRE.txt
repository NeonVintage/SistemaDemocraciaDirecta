═══════════════════════════════════════════════════════════════════
🔄 ARCHIVOS MODIFICADOS
═══════════════════════════════════════════════════════════════════

1. api.php
   ────────
   ANTES: Credenciales hardcodeadas en el código
   AHORA: 
   - Carga configuración desde config.php
   - Usa constantes para SMTP_HOST, SMTP_PORT, etc.
   - Usa constantes para criterios de votación
   - Error claro si config.php no existe

2. config.example.php
   ──────────────────
   ANTES: Ejemplo con credenciales reales
   AHORA:
   - Ejemplo genérico con placeholders
   - Documentación extensa de todos los parámetros
   - Ejemplos para Gmail, Outlook, SendGrid, Mailgun, etc.
   - Instrucciones claras de configuración

3. README.md
   ──────────
   ANTES: Mencionaba credenciales específicas
   AHORA:
   - Sección completa de configuración SMTP
   - Ejemplos para diferentes proveedores
   - Instrucciones paso a paso
   - Enlaces a recursos útiles

4. LEEME.txt
   ──────────
   ANTES: Incluía credenciales del servidor
   AHORA:
   - Guía visual de configuración
   - Ejemplos detallados con formato
   - Advertencias sobre seguridad
   - Proveedores gratuitos recomendados

5. INSTALL.txt
   ────────────
   ANTES: Instalación sin mencionar config.php
   AHORA:
   - Paso 2 dedicado a configuración de email
   - Múltiples ejemplos de proveedores
   - Solución de problemas común
   - Checklist de verificación

6. .gitignore
   ───────────
   ANTES: Solo ignoraba data/
   AHORA:
   - Ignora config.php (contiene credenciales)
   - Protege datos sensibles
   - Evita commits accidentales

🚀 CÓMO USAR ESTA VERSIÓN
═══════════════════════════════════════════════════════════════════

PARA USUARIOS NUEVOS:
─────────────────────
1. Descarga el código
2. Lee INSTALL.txt o CONFIGURACION.txt
3. Copia config.example.php a config.php
4. Configura tus credenciales SMTP
5. Sube al servidor
6. ¡Funciona!

PARA ACTUALIZAR DESDE VERSIÓN ANTERIOR:
────────────────────────────────────────
1. Respalda tu directorio data/
2. Actualiza todos los archivos excepto data/
3. Crea config.php con tus credenciales antiguas:
   
   define('SMTP_HOST', 'mail.neonvintage.com.ar');
   define('SMTP_PORT', 25);
   define('SMTP_USERNAME', 'sistemademocraciadirecta@neonvintage.com.ar');
   define('SMTP_PASSWORD', 'Sasamango292*');
   define('SMTP_FROM_EMAIL', 'sistemademocraciadirecta@neonvintage.com.ar');
   define('SMTP_FROM_NAME', 'Sistema Democracia Directa');
   define('SITE_URL', 'https://tudominio.com');

4. Todo seguirá funcionando igual
