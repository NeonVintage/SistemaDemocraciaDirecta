=====================================================
SISTEMA DEMOCRACIA DIRECTA ARGENTINA
Guía de Instalación Completa
=====================================================

PASO 1: SUBIR ARCHIVOS
-----------------------
1. Descarga todos los archivos del sistema
2. Sube todos los archivos a tu servidor web
   - Puede ser: public_html, www, htdocs, etc.
3. Asegúrate de mantener la estructura de archivos

PASO 2: CONFIGURAR EMAIL (⚠️ REQUERIDO)
----------------------------------------
El sistema NECESITA un servidor SMTP para enviar emails
de verificación. Sin esto, NO funcionará.

1. Copia el archivo de configuración:
   - En Linux/Mac: cp config.example.php config.php
   - En Windows: Copia config.example.php y renómbralo a config.php

2. Edita config.php con tu editor de texto favorito

3. Configura tus credenciales SMTP:

   EJEMPLO PARA GMAIL:
   ─────────────────────────────────────────────────
   define('SMTP_HOST', 'smtp.gmail.com');
   define('SMTP_PORT', 587);
   define('SMTP_USERNAME', 'tu-email@gmail.com');
   define('SMTP_PASSWORD', 'tu-contraseña-aplicacion');
   define('SMTP_FROM_EMAIL', 'tu-email@gmail.com');
   define('SMTP_FROM_NAME', 'Sistema Democracia');
   define('SITE_URL', 'https://tudominio.com');
   
   ⚠️ Gmail requiere "Contraseña de aplicación":
   https://myaccount.google.com/apppasswords

   EJEMPLO PARA OUTLOOK:
   ─────────────────────────────────────────────────
   define('SMTP_HOST', 'smtp-mail.outlook.com');
   define('SMTP_PORT', 587);
   define('SMTP_USERNAME', 'tu-email@outlook.com');
   define('SMTP_PASSWORD', 'tu-contraseña');
   define('SMTP_FROM_EMAIL', 'tu-email@outlook.com');
   define('SMTP_FROM_NAME', 'Sistema Democracia');
   define('SITE_URL', 'https://tudominio.com');

   EJEMPLO PARA HOSTING/cPanel:
   ─────────────────────────────────────────────────
   define('SMTP_HOST', 'mail.tudominio.com');
   define('SMTP_PORT', 25);
   define('SMTP_USERNAME', 'sistema@tudominio.com');
   define('SMTP_PASSWORD', 'contraseña-del-email');
   define('SMTP_FROM_EMAIL', 'sistema@tudominio.com');
   define('SMTP_FROM_NAME', 'Sistema Democracia');
   define('SITE_URL', 'https://tudominio.com');

Ver más ejemplos en config.example.php

PASO 3: VERIFICAR REQUISITOS
-----------------------------
✓ PHP 7.4 o superior
✓ Archivo config.php creado y configurado
✓ Permisos de escritura en el directorio

PASO 4: CONFIGURAR PERMISOS (Linux/Unix)
-----------------------------------------
Si estás en Linux, ejecuta estos comandos:

chmod 755 .
chmod 644 *.php
chmod 644 *.html
chmod 644 *.js
chmod 644 *.css

El directorio data/ se creará automáticamente.

PASO 5: ACCEDER AL SISTEMA
---------------------------
1. Abre tu navegador
2. Navega a: http://tudominio.com/index.html
3. Regístrate con tu email
4. Revisa tu correo para verificar la cuenta
5. ¡Listo para usar!

=====================================================
SOLUCIÓN DE PROBLEMAS
=====================================================

Problema: "Error: config.php no encontrado"
───────────────────────────────────────────
Solución: 
- Copia config.example.php a config.php
- Asegúrate de que esté en el mismo directorio
  que api.php

Problema: "Error de conexión. Intente nuevamente"
──────────────────────────────────────────────────
Solución:
1. Verifica que config.php exista
2. Accede a: http://tudominio.com/check-php.php
3. Accede a: http://tudominio.com/debug-api.php
4. Revisa qué tests fallan

Problema: No llegan los emails de verificación
───────────────────────────────────────────────
Solución:
1. Verifica credenciales en config.php
2. Para Gmail: usa "Contraseña de aplicación"
3. Prueba con puerto 587 en lugar de 25
4. Revisa spam/correo no deseado
5. Consulta el error_log de PHP

Problema: Error 500 en api.php
───────────────────────────────
Solución:
1. Verifica versión de PHP (debe ser 7.4+)
2. Revisa permisos de archivos
3. Accede a debug-api.php para ver detalles
4. Revisa el error_log del servidor

Problema: No se crean archivos JSON
────────────────────────────────────
Solución:
- Verifica permisos de escritura
- Temporalmente: chmod 777 . (para probar)
- Luego vuelve a: chmod 755 .

=====================================================
VERIFICACIÓN MANUAL DE USUARIOS
=====================================================

Si los emails no funcionan temporalmente:

1. El usuario se registra en el sistema
2. Se crea en data/users.json con verified: false
3. Edita data/users.json manualmente:
   Busca el usuario y cambia:
   "verified": false → "verified": true
4. Guarda el archivo
5. El usuario ya puede iniciar sesión

⚠️ Esto es solo temporal para pruebas

──────────
